Difference Between a Struct and a Mapping
Concept:
* Struct: Think of a struct like a folder or a custom data type. It groups different types of data (like a string, a number, and a boolean) together into a single object. It represents "one thing" with many details.
* Mapping: Think of a mapping like a dictionary or a phone book. It links a unique key (like a phone number) to a value (like a name). It is used for lookups.
  
Example Explanation:
Imagine you are building a School System:
* Struct (The Student's Profile):
   You use a struct to define what a "Student" is. A student has a name (string), an age (uint), and a grade (uint). These are different data types grouped together to describe one person.
* Mapping (The School Register):
   You use a mapping to find a specific student using their ID card number. You give the mapping an ID (key), and it returns the Student struct (value).
